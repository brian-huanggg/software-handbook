# 交稿檢查清單

逐項檢查；任何一項沒通過，修正後再交稿，或在回報中說明原因。

## 結構

- [ ] 檔案路徑與 frontmatter 符合 SKILL.md 的規定
- [ ] 八個 `##` 標題與 `template.md` 完全一致，順序正確
- [ ] 所有 template 註解都已刪除
- [ ] 「怎麼運作」結尾回答了「先想想」的問題
- [ ] 「取捨與替代方案」有比較表與「什麼時候不該用」
- [ ] 「常見坑」每個都有 症狀 → 原因 → 對策

## 內容

- [ ] 字數在該層級的範圍內
- [ ] 沒有用到讀者還沒學過的概念；需要用到時附上章節連結
- [ ] 至少一張圖
- [ ] 例子使用短網址服務，且版本與層級相符
- [ ] 術語與 `docs/glossary.md` 一致，新術語已加入
- [ ] 沒有編造的連結、數字或事故

## 程式碼

- [ ] `examples/...` 存在，且有測試
- [ ] 文章中的片段與範例檔案內容一致
- [ ] `go vet ./...` 與 `go test ./...` 通過（或已註明未執行）

## 資安主題（若適用）

- [ ] 攻擊只針對本機範例程式，並附上授權提醒
- [ ] 每個攻擊都有修補方式與驗證步驟
