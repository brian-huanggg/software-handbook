# AI 理論基礎目錄

本軌道回答「模型裡面到底發生什麼事」：從需要的數學開始，經過經典機器學習與深度學習，一路走到親手訓練一個小型語言模型，並讀懂大型語言模型的訓練與對齊流程。
讀者是會寫程式、但沒有機器學習背景的工程師。主要語言是 **Python**（NumPy、pandas、scikit-learn、PyTorch），專案用 `uv` 管理。

**先修**：會寫基本的 Python；高中數學（函數、指數與對數）。其餘數學在 L1 從工程師需要的角度重講。

**同一個 AI 領域的其他軌道**：應用工程（`docs/contents/ai/engineering.md`）不需要先讀本軌道；讀過本軌道的 L3、L4，會更懂應用工程裡每個參數與取捨背後的原因。

**算力**：L1–L3 的範例都能在筆電 CPU 上跑完。L4 的「從零訓練小型 GPT」在 CPU 上要跑數小時，文中會同時給出縮小版設定與免費雲端 GPU（例如 Colab）的做法，不假設讀者有 GPU。

**貫穿的例子**：

- L1–L2：表格資料（房價、客戶流失）與小型影像資料（MNIST），用來練資料處理、訓練與評估。
- L3–L4：一份繁體中文文字語料，從字元級語言模型一路長成小型 GPT，讓讀者親眼看到「預測下一個 token」怎麼變成會寫字的模型。

| 層級 | 主題 | 讀完你能做到 |
| --- | --- | --- |
| L1 數學與工具 | 線性代數、微積分、機率統計、NumPy 與資料處理 | 看懂機器學習程式與論文裡的公式，並用程式驗證它 |
| L2 經典機器學習 | 監督式與非監督式學習、模型評估、特徵工程 | 為一個表格資料問題訓練並正確評估模型 |
| L3 深度學習 | 神經網路、反向傳播、PyTorch、CNN、RNN、注意力 | 從零寫出並訓練一個神經網路，診斷它為什麼學不好 |
| L4 大型語言模型 | Transformer、預訓練、微調、對齊、推論最佳化、擴展定律 | 解釋一個 LLM 從資料到上線的每一步，並微調一個開源模型 |

寫目錄時沿用本檔格式：`##` 為層級、`### <節號> <名稱>` 為節、`- [ ]` 為文章。
每新增一節，同時在 `site/src/sidebar/ai.ts` 的 `foundations` 軌道加上該節的標籤與目錄名稱。
