# 資安目錄

本領域從**攻擊者的視角**學資安：像一次滲透測試那樣，從偵察、找漏洞、取得存取，一路走到寫報告，再從防守方把同樣的攻擊看一遍。
讀者是會寫後端服務的工程師，想理解攻擊怎麼發生、怎麼在自己的程式與系統裡修補。範例語言是 Go、Python、Bash。

**先修**：計算機科學領域的作業系統、網路、命令列章節（`docs/contents/cs.md`）。

本領域**依一次委託的階段分組**（P0–P7），不是 L0–L4。前面是攻擊鏈的順序，最後兩個階段把視角轉回防守與交付。
每一個攻擊章節都必須在同一篇裡附上**偵測與修補**，並驗證修補後攻擊確實失效——這是本領域的硬規則。

| 階段 | 主題 | 讀完你能做到 |
| --- | --- | --- |
| P0 準備 | 法律倫理、授權範圍、搭實驗室、應用密碼學 | 在授權範圍內合法地測試 |
| P1 偵察與列舉 | 對自己的資產做資訊蒐集、掃描、服務列舉 | 畫出一個目標的攻擊面 |
| P2 Web 滲透 | OWASP 類漏洞在自己的服務上實作、利用、修補 | 找出並修好 Web 應用的常見漏洞 |
| P3 系統與網路滲透 | 取得存取、權限提升、在實驗網路中橫向移動 | 在實驗室裡從初始存取走到網域管理 |
| P4 進階技術 | 逆向、二進位漏洞、雲與容器攻擊面、CTF 方法 | 面對沒有現成工具的題目 |
| P5 紅隊行動 | ATT&CK、對手模擬規劃、紫隊協作 | 規劃一次有目標的演練 |
| P6 防禦與應變 | 偵測、強化、事故應變、數位鑑識 | 從防守方看見並擋下同樣的攻擊 |
| P7 報告與職涯 | 寫滲透報告、漏洞賞金與負責任揭露、證照路線 | 把發現變成能交付的成果 |

寫目錄時沿用本檔格式：`##` 為階段、`### <節號> <名稱>` 為節、`- [ ]` 為文章。
每新增一節，同時在 `site/src/sidebar/cyber.ts` 加上該節的標籤與目錄名稱。

> **授權與範圍**：本領域所有實作只在你自己擁有或獲得書面授權的系統上進行——你本機的範例服務、實驗室裡刻意設計的脆弱標靶（如 Juice Shop、DVWA 這類），以及正規 CTF 平台。
> 絕不針對第三方系統或真實網站。不教大規模掃描、不教規避防毒／端點偵測、不教清除蹤跡。紅隊章節只到規劃、ATT&CK 對應與報告的層次。

## P0 準備：先把界線與實驗室立好

資安學習最危險的不是技術，是沒搞清楚「可以對誰做」。這一階段先把法律、倫理、範圍講清楚，再把一個安全的練習環境架起來。

### 0.1 倫理、法律與授權

- [ ] 授權測試 vs 未授權存取：法律上的那條線
- [ ] 範圍（scope）與交戰規則（rules of engagement）
- [ ] 負責任揭露的基本精神
- [ ] 本書的紅線：哪些事這裡不做，為什麼

### 0.2 搭建自己的實驗室

- [ ] 用虛擬機／容器建一個隔離的練習網路
- [ ] 常見的刻意脆弱標靶與它們各自練什麼
- [ ] 攻擊機（如 Kali）的工具總覽
- [ ] 做快照與還原：弄壞了能一鍵回復

### 0.3 應用密碼學

- [ ] CIA：機密性、完整性、可用性
- [ ] 雜湊、對稱與非對稱加密各解決什麼
- [ ] TLS 握手複習：攻擊者看得到什麼、看不到什麼
- [ ] 常見密碼學誤用：弱雜湊、自己造加密、亂數不夠亂

## P1 偵察與列舉：畫出攻擊面

拿到一個授權目標，第一件事不是攻擊，是理解它。學會系統化地蒐集資訊、找出開了哪些服務、列舉出可下手的點。

### 1.1 被動偵察（OSINT）

- [ ] 公開資訊蒐集的思路（對自己的資產練習）
- [ ] 子網域、憑證透明度、公開洩漏的面向
- [ ] 把蒐集到的資訊整理成攻擊面地圖

### 1.2 主動掃描

- [ ] 主機探活與埠掃描（nmap）
- [ ] 服務與版本辨識
- [ ] 掃描的侵入性與節制：為什麼不做大規模掃描

### 1.3 服務與 Web 列舉

- [ ] 常見服務的列舉：SMB、SSH、資料庫等
- [ ] Web 內容探索：目錄、參數、API 端點
- [ ] 漏洞掃描器的角色與它的盲點

### 1.4 防守視角

- [ ] 偵察在防守端長什麼樣：異常掃描的偵測
- [ ] 減少攻擊面：關掉不需要的服務、收斂資訊外洩

## P2 Web 滲透：在自己的服務上攻防

把後端領域那個短網址服務（或刻意脆弱的標靶）當標靶，逐一重現 OWASP 類漏洞，利用它，然後在程式裡修好，再確認攻擊失效。

### 2.1 攔截與觀察

- [ ] 用攔截代理（如 Burp）看懂一個請求怎麼被改
- [ ] 手動改請求與重放

### 2.2 注入類

- [ ] SQL injection：原理、利用、參數化修補
- [ ] 命令注入與修補
- [ ] 不安全的反序列化概念與防範

### 2.3 跨站與請求偽造

- [ ] CSRF：原理與 token／SameSite 修補

### 2.5 API 與現代前端
