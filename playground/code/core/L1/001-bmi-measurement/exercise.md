# 001 BMI Measurement

> BMI = Weight / Height²
> Weight (kilogram) and Height (meter)

## International Standard BMI Categories (WHO / CDC)

• Underweight: BMI < 18.5
• Normal / Healthy Weight: BMI 18.5 to 24.9
• Overweight: BMI 25.0 to 29.9
• Obesity Class 1: BMI 30.0 to 34.9
• Obesity Class 2: BMI 35.0 to 39.9
• Obesity Class 3 (Severe Obesity): BMI ≥ 40.0
