# 002 Temperature Conversion

把攝氏溫度轉成華氏與克氏，印成對照表。

## 需求

- 寫兩個函式：`celsius_to_fahrenheit(c)` 與 `celsius_to_kelvin(c)`。
- 公式：`F = C × 9 / 5 + 32`、`K = C + 273.15`。
- 公式中的數字（`9`、`5`、`32`、`273.15`）宣告成具名常數。
- 從 -40°C 到 100°C，每 20 度印一列，小數取 1 位（克氏取 2 位）。

## 範例輸出

```
    C        F         K
  -40    -40.0    233.15
  -20     -4.0    253.15
    0     32.0    273.15
   20     68.0    293.15
   40    104.0    313.15
   60    140.0    333.15
   80    176.0    353.15
  100    212.0    373.15
```

## 觀察

- 把公式寫成 `C * (9 / 5) + 32`，在你的語言會得到什麼？為什麼？

## 練習重點

- 整數除法與浮點數除法
- 具名常數
- 格式化輸出：寬度、小數位數、靠右對齊
