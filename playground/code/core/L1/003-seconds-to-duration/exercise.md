# 003 Seconds to Duration

把秒數轉成「天、時、分、秒」的可讀格式。

## 需求

- 寫函式 `format_duration(seconds) -> string`，輸入為非負整數。
- 用整數除法與取餘數計算各單位，不使用任何時間函式庫。
- 每個單位的秒數（60、3600、86400）宣告成常數。
- 值為 0 的單位不印出；輸入為 0 時輸出 `0s`。

## 範例

| 輸入 | 輸出 |
|---|---|
| `0` | `0s` |
| `59` | `59s` |
| `3661` | `1h 1m 1s` |
| `86400` | `1d` |
| `98765` | `1d 3h 26m 5s` |

## 練習重點

- 整數型別、`/` 與 `%`
- 常數
- 字串組合
