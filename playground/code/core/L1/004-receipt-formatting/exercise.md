# 004 Receipt Formatting

計算購物清單的金額，印成對齊的收據。

## 需求

- 商品資料寫死在程式中：

  | 名稱 | 單價 | 數量 |
  |---|---|---|
  | Latte | 4.50 | 2 |
  | Bagel | 2.25 | 3 |
  | Juice | 3.10 | 1 |

- 金額一律用「分」（整數）計算與儲存，只在輸出時轉成小數。
- 稅率 5%，四捨五入到分。
- 名稱靠左對齊，數量與金額靠右對齊。

## 範例輸出

```
Item        Qty   Amount
Latte         2     9.00
Bagel         3     6.75
Juice         1     3.10
------------------------
Subtotal           18.85
Tax (5%)            0.94
Total              19.79
```

## 觀察

- 印出 `0.1 + 0.2` 的結果，並解釋為什麼金額不用浮點數儲存。

## 練習重點

- 整數與浮點數的取捨
- 型別轉換：整數轉小數
- 四捨五入
- 格式化輸出：欄寬與對齊
