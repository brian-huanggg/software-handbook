# 005 String Number Conversion

把字串轉成數字或布林值，並觀察數字型別之間的轉換。

## 需求

### Part 1：字串轉型別

- 輸入字串清單：`"42"`、`"-7"`、`"3.14"`、`"1e3"`、`"true"`、`"abc"`、`" 12 "`。
- 依序嘗試轉成整數、浮點數、布林值，印出第一個成功的型別與值。
- 都失敗時印出 `cannot convert`。
- 布林值只接受 `"true"` 與 `"false"`。

### Part 2：數字轉型別

印出以下運算的結果：

- `7 / 2`（兩個整數）
- `7` 轉浮點數後除以 `2`
- `3.99` 轉整數
- `-3.99` 轉整數

## 範例輸出（Part 1）

```
"42"   -> int 42
"-7"   -> int -7
"3.14" -> float 3.14
"1e3"  -> float 1000
"true" -> bool true
"abc"  -> cannot convert
```

`" 12 "` 的結果依語言而定，記錄在 `notes.md`。

## 觀察

- 你的語言轉整數時，是否接受前後空白？
- 浮點數轉整數是無條件捨去、四捨五入，還是往零取整？
- 有些語言把任何非空字串都當成 `true`。你的語言呢？

## 練習重點

- 字串與數字互轉
- 轉換失敗的回報方式
- 截斷（truncation）與取整方向
