# 006 Grade Letter

把分數換成等第。

## 需求

- 寫函式 `to_grade(score) -> string`，`score` 為整數。
- 分數不在 0–100 之間時回傳 `invalid`，並在函式開頭先處理（提早 return）。
- 等第規則：

  | 分數 | 等第 |
  |---|---|
  | 90–100 | A |
  | 80–89 | B |
  | 70–79 | C |
  | 60–69 | D |
  | 0–59 | F |

- 用 `switch`（或你的語言中最接近的語法）實作，不要寫成一串巢狀 `if`。

## 範例

| 輸入 | 輸出 |
|---|---|
| `100` | `A` |
| `95` | `A` |
| `89` | `B` |
| `60` | `D` |
| `59` | `F` |
| `0` | `F` |
| `-1` | `invalid` |
| `101` | `invalid` |

## 練習重點

- 提早 return（guard clause）
- `switch` 與範圍判斷
- 邊界值測試
