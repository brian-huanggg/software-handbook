# 008 Days in Month

判斷閏年，並計算某年某月有幾天。

## 需求

- `is_leap(year) -> bool`：能被 4 整除且不能被 100 整除，或能被 400 整除。
- `days_in_month(year, month) -> int`：用 `switch` 處理，同天數的月份合併成同一個 `case`。
- 月份不在 1–12 時回傳 `0`，由呼叫端判斷並印出 `invalid month`。
- `days_in_year(year) -> int`：用迴圈累加 12 個月的天數，不要直接用 `is_leap` 回傳 365 或 366。

## 範例

| 輸入 | 輸出 |
|---|---|
| `2024, 2` | `29` |
| `1900, 2` | `28` |
| `2000, 2` | `29` |
| `2023, 4` | `30` |
| `2023, 13` | `invalid month` |
| `days_in_year(2024)` | `366` |

## 練習重點

- 布林運算子 `&&`、`||` 與優先順序
- `switch` 一個 `case` 對應多個值
- 用特殊回傳值表示無效輸入（D 章會改用錯誤處理）
