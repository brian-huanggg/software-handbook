# 014 Recursion

用遞迴與迴圈實作同一個問題，比較兩者。

## 需求

- `factorial(n)`：遞迴版。印出 `0!` 到 `21!`。
- `fib_recursive(n)`：直接遞迴，`fib(0) = 0`、`fib(1) = 1`。用一個計數器記錄被呼叫的次數。
- `fib_iterative(n)`：用迴圈實作。
- `sum_digits(n)`：遞迴計算整數各位數字的和，例如 `sum_digits(9045) = 18`。

## 範例

| 呼叫 | 結果 |
|---|---|
| `factorial(20)` | `2432902008176640000` |
| `factorial(21)` | 依語言而定 |
| `fib_recursive(30)` | `832040`，呼叫 `2692537` 次 |
| `fib_iterative(50)` | `12586269025` |
| `sum_digits(9045)` | `18` |

## 觀察

- `21!` 超過 64 位元整數的上限。你的語言會溢位成錯誤的數字、自動換成大數，還是報錯？
- `fib_recursive(40)` 要跑多久？為什麼比迴圈版慢這麼多？

## 練習重點

- 遞迴的終止條件
- 遞迴與迴圈的效能差異
- 整數溢位
