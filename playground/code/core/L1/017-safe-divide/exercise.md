# 017 Safe Divide

觀察語言內建的除以零行為，再寫出安全的版本。

## 需求

### Part 1：觀察

分別執行以下運算，記錄結果在 `notes.md`：

- 整數 `1 / 0`
- 浮點數 `1.0 / 0`
- 浮點數 `0.0 / 0`

### Part 2：安全版本

- `safe_divide(a, b)`：`b` 為 0 時回傳錯誤（或丟出例外），不讓程式崩潰。
- `main` 對以下數對逐一呼叫，錯誤時印出訊息後繼續下一筆：

  `(10, 2)`、`(7, 0)`、`(-9, 3)`、`(0, 5)`

## 範例輸出

```
10 / 2 = 5
7 / 0 -> error: division by zero
-9 / 3 = -3
0 / 5 = 0
```

## 觀察

- 浮點數除以零在多數語言不會報錯，而是得到 `Inf` 或 `NaN`。為什麼？
- 你的語言把整數除以零視為可恢復的錯誤，還是讓程式直接崩潰？

## 練習重點

- 錯誤值與例外的差異
- 呼叫端處理錯誤後繼續執行
- `Inf` 與 `NaN`
