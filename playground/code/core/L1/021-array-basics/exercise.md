# 021 Array Basics

用固定長度的陣列做走訪與原地修改。

## 需求

- 一週的氣溫，用固定長度 7 的陣列儲存：`[23, 25, 19, 30, 28, 21, 26]`（週一到週日）。
- 印出：
  - 最高溫與是星期幾
  - 最低溫與是星期幾
  - 平均溫度（小數 2 位）
  - 高於平均的天數
- 原地反轉陣列，不建立新陣列。

## 範例輸出

```
Max: 30 (Thu)
Min: 19 (Wed)
Avg: 24.57
Days above avg: 4
Reversed: [26 21 28 30 19 25 23]
```

## 觀察

- 把陣列指定給另一個變數，修改新變數後，原陣列會不會改變？對照 013 的結論。

## 練習重點

- 陣列宣告與索引
- 用索引走訪與用元素走訪
- 雙指標原地反轉
