AI 領域分成三條軌道，依「理解模型 → 用模型做產品 → 讓模型採取行動」的順序排列。主要語言是 Python。

| 軌道 | 回答的問題 | 先修 |
| --- | --- | --- |
| 理論基礎 | 模型裡面到底發生什麼事？從數學、經典機器學習、深度學習到 LLM 的訓練與對齊 | 基本 Python |
| 應用工程 | 怎麼用模型做出可靠的產品？API、RAG、評估、上線與自架模型 | 基本 Python、HTTP API |
| 代理人 | 怎麼讓模型自己採取行動？工具呼叫、MCP、記憶、多代理人與安全 | 應用工程 L1–L2 |

理論基礎與應用工程可以分開讀，也可以並行；想盡快做出東西，就從應用工程開始，遇到「為什麼」再回到理論基礎。

## 理論基礎

L1 數學與工具 → L2 經典機器學習 → L3 深度學習 → L4 大型語言模型。

## 應用工程

L1 呼叫模型 → L2 檢索增強 → L3 品質與上線 → L4 自架與架構。

## 代理人

L1 工具與迴圈 → L2 記憶與規劃 → L3 多代理人與工作流程 → L4 正式環境的代理人。
