本領域以 Go 為主要語言，分五層帶你從電腦基礎走到分散式系統與架構決策。

| 層級 | 主題 | 讀完你能做到 |
| --- | --- | --- |
| L0 基礎 | 電腦、作業系統、網路、工具 | 看懂一個請求從瀏覽器到伺服器經過什麼 |
| L1 入門 | Go 語言、HTTP 服務、SQL、測試 | 獨立寫出一個有資料庫的 API |
| L2 中階 | 資料庫深入、並行、快取、佇列、容器 | 讓服務穩定上線並看得到它的狀態 |
| L3 資深 | 分散式系統、架構、效能、雲原生 | 設計能水平擴展、能容錯的系統 |
| L4 架構 | 可靠性、安全、成本、技術決策 | 為整個產品的後端方向負責 |

## 全書專案：短網址服務

同一個短網址服務貫穿整個後端領域。每一版都因為上一版遇到瓶頸而引入新概念：L1 完成 v1，L2 是 v2，依此類推。
