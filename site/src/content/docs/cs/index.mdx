後端、DevOps、資安三個領域都假設你讀過這裡的對應章節。目標是讓你能講清楚「一個請求從瀏覽器到伺服器」沿途的每一層在做什麼。

本領域依主題分組，每一組都從零講起，不假設任何背景。主要語言是 Go，少數底層章節會用一點 C。

| 主題 | 讀完你能做到 |
| --- | --- |
| C 計算機組成與程式執行 | 說清楚程式從原始碼到在 CPU 上執行的每一步 |
| D 資料結構與演算法 | 選對資料結構，估得出一段程式的時間複雜度 |
| O 作業系統 | 解釋 process、記憶體、I/O 與並行背後發生的事 |
| N 計算機網路 | 追蹤一個封包從你的機器到對端的完整路徑 |
| T 命令列與開發工具 | 在終端機裡自在地操作、除錯與版本控制 |
