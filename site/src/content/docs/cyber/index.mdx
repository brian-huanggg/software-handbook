title: 資安
description: 理解攻擊怎麼發生，並在自己的程式裡修補它。
---

本領域從攻擊者的視角學資安：像一次滲透測試那樣，從偵察、找漏洞、取得存取，一路走到寫報告，再從防守方把同樣的攻擊看一遍。讀者是會寫後端服務的工程師，想理解攻擊怎麼發生、怎麼在自己的程式與系統裡修補。範例語言是 Go、Python、Bash。

**先修**：[計算機科學](/cs/)的作業系統、網路、命令列章節。

:::caution
本領域的所有攻擊示範，只能在你自己擁有或獲得授權的系統上執行。範圍包括你本機的範例服務、實驗室裡刻意設計的脆弱標靶（如 Juice Shop、DVWA），以及正規 CTF 平台。絕不針對第三方系統或真實網站。
:::

本領域依一次委託的階段分組（P0–P7）。前面是攻擊鏈的順序，最後兩個階段把視角轉回防守與交付。每一個攻擊章節都會在同一篇附上偵測與修補，並驗證修補後攻擊確實失效。

| 階段 | 主題 | 讀完你能做到 |
| --- | --- | --- |
| P0 準備 | 法律倫理、授權範圍、搭實驗室、應用密碼學 | 在授權範圍內合法地測試 |
| P1 偵察與列舉 | 對自己的資產做資訊蒐集、掃描、服務列舉 | 畫出一個目標的攻擊面 |
| P2 Web 滲透 | OWASP 類漏洞在自己的服務上實作、利用、修補 | 找出並修好 Web 應用的常見漏洞 |
| P3 系統與網路滲透 | 取得存取、權限提升、在實驗網路中橫向移動 | 在實驗室裡從初始存取走到網域管理 |
| P4 進階技術 | 逆向、二進位漏洞、雲與容器攻擊面、CTF 方法 | 面對沒有現成工具的題目 |
| P5 紅隊行動 | ATT&CK、對手模擬規劃、紫隊協作 | 規劃一次有目標的演練 |
| P6 防禦與應變 | 偵測、強化、事故應變、數位鑑識 | 從防守方看見並擋下同樣的攻擊 |
| P7 報告與職涯 | 寫滲透報告、漏洞賞金與負責任揭露、證照路線 | 把發現變成能交付的成果 |

## 本領域不做的事

不教大規模掃描，不教規避防毒或端點偵測，不教清除蹤跡。紅隊章節只到規劃、ATT&CK 對應與報告的層次。

左側欄只列出已經寫好的章節，其餘章節陸續補上。
