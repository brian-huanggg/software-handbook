---

本領域寫給已經會寫後端服務、想把它自動建置、部署到正式環境並讓它長期穩定運作的人。主要工具是 Linux、Git、容器、Terraform、Ansible、Kubernetes 與 Prometheus 一家；範例以 Bash、YAML、HCL 為主。

**先修**：[計算機科學](/cs/)的作業系統、網路、命令列與 Git 章節。這些不再重講，只在需要時連回去。

| 層級 | 主題 | 讀完你能做到 |
| --- | --- | --- |
| L0 系統管理 | Linux 主機、服務、網路、腳本 | 讓一台 Linux 主機穩定地跑著服務 |
| L1 交付流水線 | Git 工作流、CI、容器映像、倉庫 | 讓程式自動變成可部署的映像 |
| L2 基礎設施即程式碼 | Terraform、Ansible、環境、秘密 | 用程式碼重建一整套環境 |
| L3 叢集營運 | Kubernetes、Helm、GitOps、可觀測性 | 在叢集上部署並營運服務 |
| L4 SRE 與平台 | SLO、事故、容量、FinOps、平台工程 | 為可靠性與成本負責 |

## 貫穿專案：營運短網址服務

[後端](/backend/)領域的短網址服務，在這裡是「要營運的系統」。從手動架一台機器開始，一路演進到用 GitOps 管理整座叢集。每一層都由上一層的痛點推著你採用新工具，而不是為了用工具而用工具。
