本領域寫給自學的初級工程師，以 TypeScript 與 React 為主，從瀏覽器怎麼把程式變成畫面，一路走到能安全對接後端、能測試、能部署的單頁應用。

**先修**：[計算機科學](/cs/)的網路與瀏覽器部分（HTTP、同源政策），以及[後端](/backend/) L1（REST、Session 與 Cookie）。本領域不再重講 HTTP 與認證原理，只講前端這一側怎麼實作。

| 層級 | 主題 | 讀完你能做到 |
| --- | --- | --- |
| L0 瀏覽器與 Web 基礎 | 渲染流程、HTML、CSS、JavaScript 核心 | 說清楚一個頁面從網址到畫面發生了什麼 |
| L1 TypeScript | 型別系統、泛型、工具鏈 | 用型別描述資料並在編譯期擋掉錯誤 |
| L2 React 核心 | 元件、狀態、Effect、表單、路由 | 獨立做出多頁面、有表單的應用 |
| L3 與後端整合 | API 呼叫、認證、伺服器狀態、檔案、資料密集畫面、並發控制 | 做出一個能安全對接後端的完整前端 |
| L4 品質與交付 | 測試、安全、無障礙、效能、建置與部署 | 讓前端可測、可信、可上線 |

## 貫穿專案

為[後端](/backend/)的短網址服務做一個管理後台：登入、列表與篩選、表單與檔案上傳、統計儀表板，涵蓋企業內部系統最常見的畫面。

## 與其他領域的分工

前端安全只講前端這一側該做什麼，攻擊原理在[資安](/cyber/)。測試策略在[測試與品質](/testing/)，這裡只講前端的工具與分層。Nginx 與 K8s 部署在[維運](/devops/)，這裡只講到「建出可部署的靜態產物」。

左側欄只列出已經寫好的章節，其餘章節陸續補上。
