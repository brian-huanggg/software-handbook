## L3 與後端整合

L3 把前端接上真實後端。每一節對應後端領域的一個設計，講前端這一側怎麼配合。

### 3.1 呼叫 API

| 標題 | 說明 |
| --- | --- |
| 封裝 `fetch` | base URL、錯誤型別與逾時 |
| 從 OpenAPI 產生型別與 client | openapi-typescript |
| 統一的錯誤處理 | 把 401、403、404、422、503 對應成畫面行為 |
| 同源部署與開發代理 | 不需要 CORS 時，開發代理與正式環境的差異 |

### 3.2 認證與 Session

| 標題 | 說明 |
| --- | --- |
| Cookie Session 的前端面 | `credentials`、`HttpOnly` 下前端讀不到的事 |
| CSRF token | 從哪裡取、怎麼帶、跨分頁同步 |
| 登入、註冊與登出流程 | 狀態機與錯誤訊息（不洩漏帳號是否存在） |
| 閒置逾時與 401 | 自動導回登入頁並保留原本要去的頁面 |
| 角色與權限畫面 | 前端隱藏按鈕不是授權 |

### 3.3 伺服器狀態

| 標題 | 說明 |
| --- | --- |
| 伺服器狀態與用戶端狀態 | 為什麼要分開管理 |
| TanStack Query | query、mutation 與快取 |
| 失效與重新取得 | mutation 後怎麼更新列表 |
| 樂觀更新與回滾 |  |
| 載入、錯誤與空狀態的設計 |  |

### 3.4 檔案上傳與下載

| 標題 | 說明 |
| --- | --- |
| `FormData` 與 multipart | 資料與檔案同一個請求 |
| 上傳前的檢查 | 副檔名、大小、MIME（前端檢查只是體驗，不是防線） |
| 上傳進度與取消 | `XMLHttpRequest` 與 `fetch` 的差異 |
| 檔案下載 | `Blob`、`Content-Disposition` 與串流 |
| 儲存服務不可用的處理 | 503 時的畫面與重試 |

### 3.5 資料密集的畫面

| 標題 | 說明 |
| --- | --- |
| 表格的分頁、排序與篩選 | 對應後端參數 |
| 搜尋輸入的 debounce | 與取消過期請求 |
| 圖表與統計儀表板 | 選圖表、無障礙配色、載入策略 |
| 匯出 Excel | 下載檔案與長時間任務的回饋 |

### 3.6 並發控制與衝突

| 標題 | 說明 |
| --- | --- |
| ETag 與 `If-Match` | 前端怎麼保存與回傳版本 |
| 處理 412 與 428 | 提示使用者並重新載入 |
| 截止時間與狀態 | 以伺服器時間為準，前端倒數只是顯示 |
| 防止重複提交與重送 | 按鈕狀態、冪等與重新整理 |
