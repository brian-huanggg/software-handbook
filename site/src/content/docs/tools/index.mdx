本領域寫給已經會寫程式、想把日常開發工具用得更熟的人。目標不是背功能清單，而是理解每一類工具解決什麼問題、核心概念是什麼，換一個產品也能很快上手。

本領域依工具類別分組，不分層級，也沒有貫穿專案。每一組都獨立，可以按需要挑著讀。

**先修**：[計算機科學](/cs/)的「命令列與開發工具」（T 組）。那裡講指令與概念的最小集合，這裡講各類工具的完整用法與工作流。

| 類別 | 讀完你能做到 |
| --- | --- |
| 編輯器與 IDE | 用導覽、重構、除錯與外掛把一個專案讀懂、改穩 |
| 終端機與 Shell 環境 | 配置順手的終端機，用多工、別名與歷史搜尋加速日常操作 |
| Git 工具 | 用圖形介面與進階指令閱讀歷史、整理 commit、處理衝突 |
| 資料庫用戶端 | 連線、查詢、看執行計畫、匯出匯入並安全地操作資料 |
| API 與網路工具 | 發請求、看回應、重現並除錯一個 HTTP 問題 |
| 除錯與效能分析 | 用除錯器與 profiler 定位錯誤與瓶頸 |

## 工具會更新，內容怎麼應對

- **教能力，不教產品**：每篇以一到兩個代表工具示範，並簡短提及替代品。
- **講穩定的部分**：以概念、工作流與命令列為主，不寫選單點擊路徑，也少用截圖。
- **精確步驟看官方文件**：本書只講「為什麼」與「什麼時候用」。
- **標示驗證版本**：每篇文章的 frontmatter 記錄工具、版本與驗證日期。

```yaml
verified:
  tool: DBeaver
  version: "25.2"
  date: 2026-11-13
```

## 與其他領域的分界

Git 的指令概念屬於[計算機科學](/cs/)；Docker、Kubernetes 等基礎設施工具屬於 [DevOps](/devops/)。本領域只寫開發者每天互動的工具。

左側欄只列出已經寫好的章節，其餘章節陸續補上。
